API 路由 · Endpoints

auth 需要登录（session）
demo Demo 用户有特殊处理
stream SSE 流式响应
public 无需认证
Method 路径 说明 标签
POST /api/process 图书入库主流程：图片 → 预处理 → AI 识别 → 查重 → 写入 Notion authdemo
GET /api/books?genre=分类名 按分类获取所有书（书名/作者/封面/状态） authdemo
GET /api/books/[pageId] 获取单本书详情（含语录、笔记等 Notion block 内容） auth
GET /api/quotes 获取所有语录，按书分组，包含封面/配乐 URL authdemo
POST /api/quotes 新增语录（关联到指定书的 Notion 页面） authdemo
PATCH /api/quotes 更新语录内容（编辑已有摘录文本） auth
POST /api/chat AI 聊书对话，SSE 流式推送，支持书籍识别/入库工具调用 authstreamdemo
POST /api/chat/save-to-notion 把 AI 对话内容保存到 Notion 指定页面 auth
POST /api/agent Tool Use Agent：多轮调用，完成"识别 → 查重 → 写 Notion"完整链路 authstreamdemo
GET /api/stats Dashboard 统计数据：总数/分类/国家/作者/月度趋势/热力图 authdemo
GET /api/daily-quote AI 生成今日语录（中英双语），Demo 用户返回固定内容 authdemo
GET /api/images?url=... 图片代理：绕过 CORS，从第三方源取图片返回给前端 auth
GET /api/images/proxy 图片代理（备用路径，与上面功能相同） auth
GET /api/music?url=... 音乐代理：为书籍匹配背景音乐，绕过 CORS 限制 auth
GET /api/videos 视频内容代理 auth
POST /api/translate-quotes 批量翻译语录（中→英 或 英→中） auth
POST /api/translate-term 翻译单个词条（Dashboard 词云标签用） auth
ANY /api/auth/[...nextauth] NextAuth.js OAuth 处理（Google 登录回调、Session、CSRF） public
GET /api/health 健康检查：验证环境变量是否完整，Vercel 监控用 public
