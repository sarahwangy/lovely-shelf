在 `docs/learning-notes.md` 末尾追加一段新的学习笔记。

按照文件里已有的格式写：

```
### T{编号} - {标题}

- **学到的核心概念：**
  - 每条一行，用通俗的话解释，括号里标注"行业通用"或"这个项目特有"

- **用到的关键 API/函数：**
  - 函数名/方法名：一句话说它做什么

- **容易踩的坑：**
  - 实际遇到的问题，不要写假设性的坑

- **一句话总结：**
  用一句话说清楚这个 ticket 做了什么、解决了什么问题。

---
```

规则：
- 编号从文件里最后一个 T 编号 +1 开始，如果用户指定了编号就用用户的
- 标题和内容根据当前对话中完成的工作来写，不要瞎编
- 写完后告诉我追加的内容，让我确认后再问我要不要 commit
